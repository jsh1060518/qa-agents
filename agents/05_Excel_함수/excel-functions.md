# Excel 함수 레퍼런스 (데이터 문서 찾기·비교용)

버전 표기: **365** = Microsoft 365 / Excel 2024 이상, **2021** = Excel 2021 이상, **전체** = 구버전 포함 대부분

---

## 1. 상황별 추천 (먼저 이 표로 판단)

| 하고 싶은 일 | 1순위 | 구버전 대안 | 비고 |
|---|---|---|---|
| 다른 파일·시트에서 같은 키의 값을 가져오기 | XLOOKUP | INDEX + MATCH, VLOOKUP | 2개 파일을 1개 파일에서 보는 가장 흔한 경우 |
| 한 키로 여러 열을 한 번에 가져오기 | XLOOKUP (반환 범위를 여러 열로) | INDEX + MATCH를 열마다 | |
| 조건에 맞는 행 전체를 걸러서 보기 | FILTER | 자동 필터, 고급 필터 | |
| 중복 없이 목록 뽑기 | UNIQUE | 데이터 → 중복 항목 제거 | |
| 두 표를 위아래로 합치기 | VSTACK | 복사·붙여넣기, 파워 쿼리 | VSTACK은 365 |
| 두 표를 옆으로 붙이기 | HSTACK | 복사·붙여넣기 | HSTACK은 365 |
| 원하는 열만 골라서 보기 | CHOOSECOLS | INDEX | 365 |
| 기획 값과 실제 값이 다른지 비교 | IF + XLOOKUP, 또는 `=A2=B2` | IF + VLOOKUP | 조건부 서식과 함께 |
| 한쪽에만 있는 데이터 찾기 | COUNTIF, 또는 ISNA + MATCH | 같음 | |
| 조건별 개수·합계 | COUNTIFS, SUMIFS | 같음 | |
| 조건별 최댓값·최솟값 | MAXIFS, MINIFS | MAX + IF (배열 수식) | 2019 이상 |
| 텍스트 나누기 (예: "A/B/C") | TEXTSPLIT | 데이터 → 텍스트 나누기, MID + FIND | TEXTSPLIT은 365 |
| 특정 글자 앞·뒤만 꺼내기 | TEXTBEFORE, TEXTAFTER | LEFT/MID + FIND | 365 |
| 여러 값을 한 셀에 이어 붙이기 | TEXTJOIN | & 연산자 | 2019 이상 |
| 특정 단어 포함 여부 | ISNUMBER + SEARCH | 같음 | |
| 오류 대신 빈칸·문구 표시 | IFERROR, IFNA | 같음 | |
| 여러 파일을 정기적으로 합치기 | **파워 쿼리** | — | 수식이 무거워질 때 |

## 2. 찾기·가져오기

| 함수 | 형식 | 설명 | 버전 |
|---|---|---|---|
| XLOOKUP | `=XLOOKUP(찾을값, 찾을범위, 가져올범위, [없을때], [일치방식], [검색방향])` | 키로 값을 찾아 가져온다. 왼쪽 열도 가져올 수 있고, 없을 때 문구를 바로 지정할 수 있다. | 2021 |
| VLOOKUP | `=VLOOKUP(찾을값, 표범위, 열번호, FALSE)` | 표의 첫 열에서 찾고 오른쪽 n번째 열 값을 가져온다. 마지막 인수는 반드시 FALSE(정확히 일치). | 전체 |
| HLOOKUP | `=HLOOKUP(찾을값, 표범위, 행번호, FALSE)` | 가로로 된 표에서 찾는다. | 전체 |
| INDEX | `=INDEX(범위, 행번호, [열번호])` | 범위에서 n번째 값을 꺼낸다. | 전체 |
| MATCH | `=MATCH(찾을값, 범위, 0)` | 값이 몇 번째에 있는지 찾는다. 0은 정확히 일치. | 전체 |
| INDEX + MATCH | `=INDEX(가져올열, MATCH(찾을값, 찾을열, 0))` | VLOOKUP의 단점(왼쪽 열 불가, 열 삽입 시 깨짐)이 없다. | 전체 |
| XMATCH | `=XMATCH(찾을값, 범위)` | MATCH의 개선판. 기본이 정확히 일치. | 2021 |
| CHOOSECOLS | `=CHOOSECOLS(범위, 열번호1, 열번호2, …)` | 원하는 열만 골라서 보여준다. | 365 |
| CHOOSEROWS | `=CHOOSEROWS(범위, 행번호1, …)` | 원하는 행만 골라서 보여준다. | 365 |

**예시: 다른 파일의 가격을 가져오기**
```
=XLOOKUP(A2, '[아이템_기획.xlsx]Item'!$A:$A, '[아이템_기획.xlsx]Item'!$D:$D, "없음")
```
- A2의 아이템ID를 `아이템_기획.xlsx` 파일 Item 시트의 A열에서 찾고, 같은 행 D열(가격)을 가져온다.

**예시: 한 번에 여러 열 가져오기**
```
=XLOOKUP(A2, Item!$A:$A, Item!$B:$E)
```
- B~E열 값이 오른쪽 셀로 함께 펼쳐진다. (365, 2021)

## 3. 걸러내기·정리

| 함수 | 형식 | 설명 | 버전 |
|---|---|---|---|
| FILTER | `=FILTER(범위, 조건, [없을때])` | 조건에 맞는 행만 보여준다. 조건 여러 개는 `(조건1)*(조건2)`=AND, `(조건1)+(조건2)`=OR | 2021 |
| UNIQUE | `=UNIQUE(범위)` | 중복을 뺀 목록 | 2021 |
| SORT | `=SORT(범위, [기준열], [1오름/-1내림])` | 정렬한 결과를 보여준다. 원본은 그대로. | 2021 |
| SORTBY | `=SORTBY(범위, 기준범위, [순서])` | 다른 열 기준으로 정렬 | 2021 |
| VSTACK | `=VSTACK(범위1, 범위2)` | 표를 위아래로 합친다. | 365 |
| HSTACK | `=HSTACK(범위1, 범위2)` | 표를 옆으로 붙인다. | 365 |
| TAKE / DROP | `=TAKE(범위, 행수)` / `=DROP(범위, 행수)` | 앞에서 n행만 / n행 빼고 | 365 |

**예시: 특정 NPC 등급이 "보스"인 행만 보기**
```
=FILTER(NPC!A2:H500, NPC!C2:C500="보스", "해당 없음")
```

**예시: 두 파일의 표를 하나로 합쳐 보기**
```
=VSTACK('[데이터1.xlsx]Sheet1'!A2:F200, '[데이터2.xlsx]Sheet1'!A2:F200)
```

## 4. 비교·검증 (기획 데이터 vs 실제 데이터)

| 목적 | 수식 | 설명 |
|---|---|---|
| 두 값이 같은지 | `=A2=B2` | TRUE/FALSE |
| 대소문자까지 같은지 | `=EXACT(A2, B2)` | |
| 기획 값과 비교해 결과 표시 | `=IF(XLOOKUP(A2, 기획!A:A, 기획!D:D)=D2, "일치", "불일치")` | |
| 한쪽에만 있는 키 | `=IF(COUNTIF(기획!A:A, A2)=0, "기획에 없음", "")` | |
| 한쪽에만 있는 키 (구버전) | `=IF(ISNA(MATCH(A2, 기획!A:A, 0)), "기획에 없음", "")` | |
| 확률 합계 확인 | `=SUMIFS(확률열, 상자ID열, "AA")` | 같은 상자의 확률 합산 |
| 범위 안 값인지 | `=AND(D2>=최솟값, D2<=최댓값)` | |

**조건부 서식으로 불일치 칠하기**
1. 비교할 범위 선택 (예: D2:D500)
2. 홈 → 조건부 서식 → 새 규칙 → "수식을 사용하여 서식을 지정할 셀 결정"
3. 수식 입력: `=D2<>XLOOKUP($A2, 기획!$A:$A, 기획!$D:$D)`
4. 채우기 색 지정

## 5. 개수·합계

| 함수 | 형식 | 설명 | 버전 |
|---|---|---|---|
| COUNTIF / COUNTIFS | `=COUNTIFS(범위1, 조건1, 범위2, 조건2)` | 조건에 맞는 개수 | 전체 |
| SUMIF / SUMIFS | `=SUMIFS(합계범위, 범위1, 조건1, …)` | 조건에 맞는 합계 | 전체 |
| AVERAGEIFS | `=AVERAGEIFS(평균범위, 범위1, 조건1)` | 조건에 맞는 평균 | 전체 |
| MAXIFS / MINIFS | `=MAXIFS(범위, 조건범위, 조건)` | 조건에 맞는 최대/최소 | 2019 |
| COUNTA / COUNTBLANK | `=COUNTA(범위)` | 비어 있지 않은 칸 / 빈칸 개수 | 전체 |
| SUMPRODUCT | `=SUMPRODUCT((조건1)*(조건2)*값범위)` | 복잡한 조건 합계 | 전체 |

- 조건에 비교 기호를 쓸 때: `">=10"`, `"<>"&A2`, `"*검*"` (와일드카드)

## 6. 텍스트 다루기

| 함수 | 형식 | 설명 | 버전 |
|---|---|---|---|
| TEXTSPLIT | `=TEXTSPLIT(텍스트, "/")` | 구분 기호로 나눠 여러 칸에 펼친다. | 365 |
| TEXTBEFORE / TEXTAFTER | `=TEXTBEFORE(A2, "_")` | 구분 기호 앞 / 뒤 | 365 |
| LEFT / RIGHT / MID | `=MID(A2, 시작, 글자수)` | 위치로 잘라내기 | 전체 |
| FIND / SEARCH | `=SEARCH("검", A2)` | 글자 위치. SEARCH는 대소문자 무시, 와일드카드 가능 | 전체 |
| TEXTJOIN | `=TEXTJOIN(", ", TRUE, 범위)` | 여러 칸을 구분 기호로 이어 붙인다. | 2019 |
| TRIM / CLEAN | `=TRIM(A2)` | 앞뒤·중복 공백 / 보이지 않는 문자 제거 | 전체 |
| SUBSTITUTE | `=SUBSTITUTE(A2, "old", "new")` | 글자 바꾸기 | 전체 |
| VALUE / TEXT | `=VALUE(A2)` / `=TEXT(A2, "0.00%")` | 텍스트→숫자 / 숫자→형식 있는 텍스트 | 전체 |

**예시: "검/반지/목걸이"에 "반지"가 들어 있는지**
```
=ISNUMBER(SEARCH("반지", A2))
```

## 7. 오류 처리·보조

| 함수 | 형식 | 설명 |
|---|---|---|
| IFERROR | `=IFERROR(수식, "없음")` | 모든 오류를 지정 값으로 |
| IFNA | `=IFNA(수식, "없음")` | #N/A만 처리 (다른 오류는 그대로 보여서 원인 찾기 쉬움) |
| LET | `=LET(이름, 값, 계산식)` | 긴 수식에 이름을 붙여 짧게. 2021 |
| HYPERLINK | `=HYPERLINK("[파일.xlsx]시트!A1", "열기")` | 다른 파일·시트로 이동하는 링크 |
| INDIRECT | `=INDIRECT("'"&A1&"'!B2")` | 셀에 적힌 시트 이름으로 참조. 다른 파일은 그 파일이 열려 있어야 함 |

**자주 나오는 오류**
| 오류 | 흔한 원인 | 해결 |
|---|---|---|
| #N/A | 찾는 값이 없음, 숫자와 텍스트 형식이 다름, 앞뒤 공백 | TRIM, VALUE로 형식 맞추기, IFNA로 표시 |
| #REF! | 참조한 열·시트·파일이 삭제되거나 이동됨 | 참조 다시 지정 |
| #VALUE! | 형식 오류. 닫힌 파일을 SUMIF/COUNTIF/INDIRECT로 참조 | 원본 파일 열기, 또는 SUMPRODUCT/XLOOKUP 사용 |
| #SPILL! | 결과가 펼쳐질 자리에 이미 값이 있음 | 아래·오른쪽 칸 비우기 |
| #NAME? | 함수 이름 오타, 내 Excel 버전에 없는 함수 | 철자 확인, 구버전 대안 사용 |

## 8. 다른 파일 참조할 때 알아둘 점
- 참조 형식: `'[파일명.xlsx]시트명'!$A:$A`
- 처음 수식을 만들 때 두 파일을 모두 열어 두고, 수식 입력 중 다른 파일의 셀을 클릭하면 경로가 자동으로 들어간다.
- 원본 파일이 닫혀 있어도 XLOOKUP, VLOOKUP, INDEX/MATCH는 마지막으로 저장된 값을 보여준다. **SUMIF, COUNTIF, INDIRECT, OFFSET은 원본이 닫히면 #VALUE! 오류**가 난다.
- 원본 파일 이름이나 위치를 바꾸면 연결이 끊긴다. 데이터 → 링크 편집에서 다시 연결한다.
- 매번 여러 파일을 합쳐야 하면 **데이터 → 데이터 가져오기 → 파일에서 → 통합 문서(파워 쿼리)**를 쓰는 편이 수식보다 가볍고 새로 고침 한 번으로 갱신된다.

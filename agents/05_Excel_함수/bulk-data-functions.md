# 대량 데이터 확인 함수 모음

아이템 100개 이상처럼 행이 많은 기획서와 데이터 문서를 확인할 때 QA에서 자주 쓰는 함수다. `/대량` 명령이나 대량 데이터 관련 요청에는 이 모음의 수식을 먼저 쓴다.

예시 기준: 기획서 시트의 A열 Alias, B열 명칭, C~F열 속성 / '데이터' 시트의 A열 alias, C~F열 값

버전 표기: **구버전 포함** / **Excel 2019 이상** / **Excel 2021 이상** / **Microsoft 365 · Excel 2024** / **Microsoft 365 전용**

## 대량 데이터에서 느려지지 않게 쓰는 법
- FILTER, UNIQUE, XLOOKUP 배열 수식의 범위는 열 전체(A:A) 대신 실제 행 수(A2:A5000)로 잡는다. 열 전체를 배열로 넘기면 100만 행을 계산한다.
- 같은 XLOOKUP을 여러 번 쓰는 수식은 LET으로 이름을 붙여 한 번만 계산한다.
- 판정이 끝난 열은 복사 → 값으로 붙여넣기 해 두면 파일이 가벼워진다.
- 수식이 많아 느리면 수식 → 계산 옵션 → 수동으로 바꾸고, 볼 때 F9로 계산한다.
- 수만 행 이상이거나 매 빌드 반복하는 비교는 파워 쿼리나 데이터 비교 도구가 더 빠르다.
- COUNTIF, SUMIF, INDIRECT는 참조한 다른 파일이 닫혀 있으면 #VALUE!가 난다. 비교할 시트를 같은 파일로 복사해 두고 쓴다.

## 값 가져오기
다른 시트·파일에서 같은 Alias의 값을 가져올 때

| 함수 | 쓰는 경우 | 수식 | 버전 | 참고 |
|---|---|---|---|---|
| XLOOKUP | Alias로 데이터 문서의 값을 가져올 때 | `=XLOOKUP(A2, 데이터!$A:$A, 데이터!$D:$D, "없음")` | Excel 2021 이상 | 없는 Alias는 "없음"으로 나온다. 왼쪽 열도 가져올 수 있다. |
| XLOOKUP (여러 열 한 번에) | 한 Alias의 속성 여러 개를 한 수식으로 가져올 때 | `=XLOOKUP(A2, 데이터!$A:$A, 데이터!$C:$F, "없음")` | Excel 2021 이상 | C~F열 값이 오른쪽으로 함께 펼쳐진다. 표(Ctrl+T) 안에서는 펼쳐지지 않으니 일반 범위에서 쓴다. |
| INDEX + MATCH | XLOOKUP이 없는 Excel에서 값을 가져올 때 | `=INDEX(데이터!$D:$D, MATCH(A2, 데이터!$A:$A, 0))` | 구버전 포함 | 없는 값은 #N/A가 나온다. IFERROR(수식, "없음")으로 감싼다. |
| XLOOKUP (기준 열 2개) | 상품 ID + 구성품 Alias처럼 두 열이 같아야 같은 행일 때 | `=XLOOKUP(A2&"\|"&C2, 데이터!$A$2:$A$5000&"\|"&데이터!$C$2:$C$5000, 데이터!$E$2:$E$5000, "없음")` | Excel 2021 이상 | 범위는 열 전체(A:A)가 아니라 실제 행 수만큼만 잡는다. 열 전체를 쓰면 매우 느려진다. |
| VLOOKUP | 구버전에서 가장 익숙한 방법으로 값을 가져올 때 | `=VLOOKUP(A2, 데이터!$A:$F, 4, FALSE)` | 구버전 포함 | 마지막 인수는 반드시 FALSE. 찾는 열이 범위의 첫 열이어야 하고, 열을 끼워 넣으면 번호가 어긋난다. |

## 값 비교
기획 값과 데이터 값이 같은지 판정할 때

| 함수 | 쓰는 경우 | 수식 | 버전 | 참고 |
|---|---|---|---|---|
| IF + XLOOKUP | 기획 값과 데이터 값이 같은지 Pass/Fail로 표시할 때 | `=IF(XLOOKUP(A2, 데이터!$A:$A, 데이터!$D:$D, "없음")=D2, "Pass", "Fail")` | Excel 2021 이상 | = 비교는 영문 대소문자를 구분하지 않는다. 데이터에 없는 Alias도 Fail이 된다. |
| 가능/불가 ↔ Y/N 비교 | 기획서는 가능/불가, 데이터 문서는 Y/N(소문자 포함)일 때 | `=IF(IF(D2="가능","Y","N")=UPPER(TRIM(XLOOKUP(A2, 데이터!$A:$A, 데이터!$D:$D, ""))), "Pass", "Fail")` | Excel 2021 이상 | UPPER로 소문자 y/n을, TRIM으로 앞뒤 공백을 맞춘다. |
| 확률·수치 비교 (오차 허용) | 0.5%와 0.005처럼 숫자 값을 비교할 때 | `=IF(ABS(XLOOKUP(A2, 데이터!$A:$A, 데이터!$C:$C, 0)-D2)<=0.000001, "Pass", "Fail")` | Excel 2021 이상 | 기획 값이 "0.5%" 텍스트면 D2 대신 VALUE(D2)를 쓴다. 소수 계산 오차 때문에 = 대신 차이의 크기로 비교한다. |
| 다른 열 이름 나열 | 아이템마다 어느 속성이 다른지 한 칸에 보고 싶을 때 | `=IFERROR(TEXTJOIN(", ", TRUE, IF(C2:F2<>XLOOKUP(A2, 데이터!$A:$A, 데이터!$C:$F), $C$1:$F$1, "")), "데이터 없음")` | Excel 2021 이상 | 빈칸이면 모두 일치. "판매 여부, 거래 여부"처럼 다른 열의 헤더가 나온다. |
| EXACT + SUMPRODUCT | 영문 대소문자까지 정확히 같은 Alias가 있는지 볼 때 | `=IF(SUMPRODUCT(--EXACT(A2, 데이터!$A$2:$A$5000))>0, "", "대소문자 다름 또는 없음")` | 구버전 포함 | = 비교와 XLOOKUP은 item_01과 ITEM_01을 같다고 본다. 대소문자가 중요한 키는 EXACT로 확인한다. |
| SUMPRODUCT (불일치 칸 수) | 행 순서와 크기가 같은 두 표에서 다른 칸이 몇 개인지 셀 때 | `=SUMPRODUCT(--(기획!C2:F200<>데이터!C2:F200))` | 구버전 포함 | 두 표의 행 순서가 같을 때만 쓴다. 순서가 다르면 XLOOKUP 비교를 쓴다. |
| BYROW + LAMBDA | 행 순서가 같은 두 표를 행마다 한 번에 판정할 때 | `=BYROW(기획!C2:F200=데이터!C2:F200, LAMBDA(r, IF(AND(r), "Pass", "Fail")))` | Microsoft 365 · Excel 2024 | 수식 하나로 200행 결과가 아래로 펼쳐진다. |

## 누락·중복
한쪽에만 있는 행, 중복된 키, 빈칸을 찾을 때

| 함수 | 쓰는 경우 | 수식 | 버전 | 참고 |
|---|---|---|---|---|
| COUNTIF (없는 값 표시) | 기획서 아이템이 데이터 문서에 있는지 표시할 때 | `=IF(COUNTIF(데이터!$A:$A, A2)=0, "데이터에 없음", "")` | 구버전 포함 | 방향을 바꿔 데이터 시트에도 넣으면 기획서에 없는 아이템을 찾는다. 참조한 파일이 닫혀 있으면 #VALUE!가 난다. |
| FILTER + COUNTIF (누락 목록) | 한쪽에만 있는 Alias를 목록으로 뽑을 때 | `=FILTER(A2:A200, COUNTIF(데이터!$A$2:$A$5000, A2:A200)=0, "없음")` | Excel 2021 이상 | 누락된 Alias만 아래로 나열된다. 이슈에 그대로 붙여넣기 좋다. |
| COUNTIF (중복 표시) | Alias가 두 번 이상 들어갔는지 표시할 때 | `=IF(COUNTIF($A:$A, A2)>1, "중복", "")` | 구버전 포함 |  |
| LET + UNIQUE + FILTER (중복 목록) | 중복된 값만 한 번씩 뽑아 볼 때 | `=LET(u, UNIQUE(A2:A200), FILTER(u, COUNTIF(A2:A200, u)>1, "중복 없음"))` | Excel 2021 이상 |  |
| COUNTA − UNIQUE (개수 대조) | 행 수와 고유 값 수가 같은지 한 칸으로 확인할 때 | `=COUNTA(A2:A5000)-ROWS(UNIQUE(FILTER(A2:A5000, A2:A5000<>"")))` | Excel 2021 이상 | 0이면 중복 없음. 기획서 아이템 수와 데이터 문서 아이템 수를 먼저 맞춰 볼 때도 COUNTA를 쓴다. |
| COUNTBLANK | 속성 칸에 빈칸이 있는 행을 찾을 때 | `=IF(COUNTBLANK(C2:F2)>0, "빈칸 있음", "")` | 구버전 포함 |  |

## 개수·합계
조건별 개수, 확률 합계, 범위를 확인할 때

| 함수 | 쓰는 경우 | 수식 | 버전 | 참고 |
|---|---|---|---|---|
| COUNTIFS | 조건에 맞는 아이템이 몇 개인지 셀 때 | `=COUNTIFS($C:$C, "전설", $G:$G, "불가")` | 구버전 포함 | 와일드카드도 된다: =COUNTIFS($A:$A, "ITEM_CR_*"). 비교 기호는 ">=10", "<>"&A2처럼 쓴다. |
| SUMIFS (확률 합계 100%) | 드랍 그룹·상자별 확률 합이 100%인지 확인할 때 | `=IF(ABS(SUMIFS($D:$D, $A:$A, A2)-1)<0.000001, "OK", "합계 "&TEXT(SUMIFS($D:$D, $A:$A, A2), "0.00%"))` | 구버전 포함 | A열이 그룹, D열이 확률. 합이 100%가 아니면 실제 합계를 보여준다. |
| MAXIFS / MINIFS | 등급별 최댓값·최솟값이 기획 범위 안인지 볼 때 | `=MAXIFS($E:$E, $C:$C, "전설")` | Excel 2019 이상 | 구버전 대안: =MAX(IF($C$2:$C$200="전설", $E$2:$E$200)) 입력 후 Ctrl+Shift+Enter. |
| COUNTIFS (범위 밖 값) | 기획 범위(AA~BB)를 벗어난 값이 몇 개인지 셀 때 | `=COUNTIFS($E:$E, "<"&$J$1)+COUNTIFS($E:$E, ">"&$J$2)` | 구버전 포함 | J1에 최솟값, J2에 최댓값을 적는다. 0이면 모두 범위 안. |
| GROUPBY | 속성 조합별로 아이템이 몇 개인지 표로 볼 때 | `=GROUPBY(C2:F200, A2:A200, COUNTA)` | Microsoft 365 전용 | Microsoft 365 전용. 아이템이 1~2개뿐인 드문 조합은 기획 실수일 수 있어 먼저 확인한다. 대안은 아래 UNIQUE + COUNTIFS. |
| UNIQUE + COUNTIFS (조합별 개수) | GROUPBY 없이 속성 조합별 개수를 볼 때 | `=UNIQUE(C2:F200)` | Excel 2021 이상 | H2에 넣으면 조합이 펼쳐진다. L2에 =COUNTIFS($C$2:$C$200, H2, $D$2:$D$200, I2, $E$2:$E$200, J2, $F$2:$F$200, K2)를 넣고 아래로 채운다. |

## 걸러 보기
조건에 맞는 행만 따로 모아 볼 때

| 함수 | 쓰는 경우 | 수식 | 버전 | 참고 |
|---|---|---|---|---|
| FILTER (조건 행만) | 조건에 맞는 아이템만 따로 모아 볼 때 | `=FILTER(A2:F200, (C2:C200="전설")*(F2:F200="불가"), "없음")` | Excel 2021 이상 | *는 AND, +는 OR. 원본은 그대로 두고 결과만 다른 곳에 펼쳐진다. |
| FILTER (Fail만 모으기) | 판정 결과가 Fail인 행만 모아 이슈에 붙일 때 | `=FILTER(A2:H200, H2:H200="Fail", "Fail 없음")` | Excel 2021 이상 |  |
| FILTER + SEARCH (포함 검색) | 이름에 특정 단어가 들어간 아이템만 볼 때 | `=FILTER(A2:F200, ISNUMBER(SEARCH("천랑", B2:B200)), "없음")` | Excel 2021 이상 | SEARCH는 대소문자를 구분하지 않는다. |
| SORTBY | 등급 → 수치처럼 여러 기준으로 정렬해 볼 때 | `=SORTBY(A2:F200, C2:C200, 1, E2:E200, -1)` | Excel 2021 이상 | 1은 오름차순, -1은 내림차순. 원본 순서는 바뀌지 않는다. |
| CHOOSECOLS | 결과에서 필요한 열만 골라 볼 때 | `=CHOOSECOLS(FILTER(A2:H200, H2:H200="Fail"), 1, 2, 8)` | Microsoft 365 · Excel 2024 | 1·2·8번째 열(Alias, 명칭, 결과)만 보여준다. |

## 값 정리
공백, 대소문자, 숫자 형식 때문에 비교가 어긋날 때

| 함수 | 쓰는 경우 | 수식 | 버전 | 참고 |
|---|---|---|---|---|
| TRIM + CLEAN | 눈에 안 보이는 공백 때문에 같은 값이 다르다고 나올 때 | `=TRIM(CLEAN(SUBSTITUTE(A2, CHAR(160), " ")))` | 구버전 포함 | 공백이 있는지 검사: =LEN(A2)<>LEN(TRIM(A2)) 가 TRUE면 앞뒤나 중간에 남는 공백이 있다. |
| VALUE / ISNUMBER | 숫자가 텍스트로 들어가 비교가 어긋날 때 | `=VALUE(D2)` | 구버전 포함 | =ISNUMBER(D2)가 FALSE면 텍스트다. VALUE는 "1,000"과 "0.5%"도 숫자로 바꾼다. |
| UPPER / LOWER | Y/N, Alias의 대소문자를 통일할 때 | `=UPPER(TRIM(D2))` | 구버전 포함 |  |
| TEXTSPLIT | "검/반지/목걸이"처럼 한 칸에 든 값을 나눌 때 | `=TEXTSPLIT(A2, "/")` | Microsoft 365 · Excel 2024 | 구버전 대안: 데이터 → 텍스트 나누기. |
| TEXTBEFORE / TEXTAFTER | Alias에서 종류나 번호 부분만 꺼낼 때 | `=TEXTAFTER(A2, "_", -1)` | Microsoft 365 · Excel 2024 | ITEM_CR_WPN_01에서 01을 꺼낸다. -1은 마지막 구분자 기준. 구버전은 LEFT / MID / FIND를 쓴다. |
| AND + LEFT + LEN + EXACT (형식 검사) | Alias가 정해진 형식인지 한 번에 검사할 때 | `=AND(LEFT(A2,5)="ITEM_", LEN(A2)=14, EXACT(A2, UPPER(A2)))` | 구버전 포함 | 접두어, 글자 수, 대문자 여부를 함께 본다. 조건은 프로젝트 규칙에 맞게 바꾼다. |

## 합치기
여러 시트나 열을 하나로 모을 때

| 함수 | 쓰는 경우 | 수식 | 버전 | 참고 |
|---|---|---|---|---|
| VSTACK | 무기·방어구·장신구처럼 나뉜 시트를 한 표로 모을 때 | `=LET(v, VSTACK(무기!A2:F100, 방어구!A2:F100, 장신구!A2:F100), FILTER(v, CHOOSECOLS(v, 1)<>""))` | Microsoft 365 · Excel 2024 | FILTER로 빈 행을 뺀다. 시트가 나란히 있으면 VSTACK(무기:장신구!A2:F100)처럼 한 번에 쓸 수 있다. |
| HSTACK + XLOOKUP | 기획 값 옆에 데이터 값을 나란히 붙여 볼 때 | `=HSTACK(A2:B200, XLOOKUP(A2:A200, 데이터!$A$2:$A$5000, 데이터!$D$2:$D$5000, "없음"))` | Microsoft 365 · Excel 2024 | Alias, 명칭, 데이터 값이 한 표로 펼쳐진다. |
| TOCOL | 여러 열에 흩어진 Alias를 한 열로 모을 때 | `=TOCOL(B2:F50, 1)` | Microsoft 365 · Excel 2024 | 두 번째 인수 1은 빈칸을 뺀다. 구성품 1~5 열에 든 Alias를 모아 UNIQUE로 목록을 만들 때 쓴다. |
| INDIRECT (시트별 행 수) | 시트 이름 목록으로 시트마다 행 수를 한눈에 볼 때 | `=COUNTA(INDIRECT("'"&A2&"'!A:A"))-1` | 구버전 포함 | A2에 시트 이름. 다른 파일을 참조할 때는 그 파일이 열려 있어야 한다. |

## 엑셀 기능
수식 대신 쓰면 빠른 엑셀 기능

| 함수 | 쓰는 경우 | 수식 | 버전 | 참고 |
|---|---|---|---|---|
| 조건부 서식 (불일치 칠하기) | 다른 값을 색으로 바로 보고 싶을 때 | `=D2<>XLOOKUP($A2, 데이터!$A:$A, 데이터!$D:$D, "")` | Excel 2021 이상 | 범위 선택 → 홈 → 조건부 서식 → 새 규칙 → "수식을 사용하여 서식을 지정할 셀 결정"에 이 수식을 넣는다. |
| 조건부 서식 (중복 값) | 수식 없이 중복된 Alias를 색으로 볼 때 | `홈 → 조건부 서식 → 셀 강조 규칙 → 중복 값` | 구버전 포함 |  |
| 표로 만들기 (Ctrl+T) | 행이 늘어도 수식 범위가 자동으로 따라오게 할 때 | `=COUNTIFS(표1[등급], "전설")` | 구버전 포함 | 표 안에서는 열 이름으로 참조한다. 필터와 정렬 버튼이 자동으로 붙는다. FILTER처럼 펼쳐지는 수식은 표 밖에 쓴다. |
| 피벗 테이블 | 등급·종류·속성별 개수를 끌어다 놓기로 볼 때 | `삽입 → 피벗 테이블 → 행에 등급·속성, 값에 Alias(개수)` | 구버전 포함 | 수식 없이 조합별 개수를 본다. 원본이 바뀌면 새로 고침을 누른다. |
| 파워 쿼리 (쿼리 병합) | 수만 행이거나 매 빌드마다 같은 비교를 반복할 때 | `데이터 → 데이터 가져오기 → 쿼리 결합 → 병합 → 조인 종류: 왼쪽 앤티(첫 번째에만 있는 행)` | 구버전 포함 | 수식보다 가볍고, 파일만 바꾼 뒤 새로 고침 한 번으로 다시 비교된다. |
| 이동 옵션 (빈 셀 선택) | 수백 행에서 빈칸만 한 번에 골라낼 때 | `범위 선택 → Ctrl+G → 옵션 → 빈 셀` | 구버전 포함 | 선택된 빈칸에 색을 칠하거나 값을 한 번에 넣을 수 있다(입력 후 Ctrl+Enter). |

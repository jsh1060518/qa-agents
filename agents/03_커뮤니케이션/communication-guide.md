# 커뮤니케이션 가이드

## 1. 대상별 어투
| 대상 | 어투 | 예시 |
|---|---|---|
| 상사/임원 | 하십시오체·해요체 혼용, 결론 먼저, 간결 | "결론부터 말씀드리면, 금일 배포는 어렵습니다." |
| 동료 | 해요체, 친근하되 명확 | "확인해 보니 재현돼요. 이슈 등록해 둘게요." |
| 타 부서 | 해요체, 배경 설명 추가 | "QA팀 OOO입니다. 어제 배포된 빌드 관련 문의드려요." |
| 외부 고객 | 하십시오체, 정중 | "불편을 드려 죄송합니다. 확인 후 회신드리겠습니다." |

## 2. 자주 틀리는 맞춤법
| 틀린 표현 | 바른 표현 |
|---|---|
| 되요 / 되서 | 돼요 / 돼서 |
| 안되요 | 안 돼요 |
| 할께요 | 할게요 |
| 몇일 | 며칠 |
| 금새 | 금세 |
| 왠만하면 | 웬만하면 |
| 어떻해 | 어떡해 / 어떻게 해 |
| 오랫만에 | 오랜만에 |
| 역활 | 역할 |
| 설겆이 | 설거지 |
| 바램 | 바람 |
| 로써/로서 혼동 | 자격: ~로서 / 수단: ~로써 |
| 결제/결재 혼동 | 돈: 결제 / 승인: 결재 |
| 재현/재연 혼동 | 버그 다시 발생: 재현 |
| 부탁드려요 | 그대로 사용 가능 (부탁드립니다가 더 격식) |
| 확인 부탁드릴께요 | 확인 부탁드릴게요 |
| 일일히 | 일일이 |
| 내노라하는 | 내로라하는 |

## 3. 띄어쓰기 주의
- 의존명사: 할 수 있다, 한 지 3일, 아는 것, 갈 데
- 단위: 3 개 → 3개(숫자와 함께면 붙여도 됨), 10 분
- "~하는데/~한 데" 구분: 연결어미는 붙임, 장소·경우는 띄움
- "안 / 않": 안 된다(부정 부사) / 하지 않다(보조용언)

## 4. 다듬기 기준
- 피할 표현 → 대안
  - "왜 안 했어요?" → "진행 상황 공유해 주실 수 있을까요?"
  - "이거 버그예요" → "확인해 보니 기대 동작과 달라 이슈로 등록했습니다."
  - "빨리 해주세요" → "OO일까지 가능할까요? 배포 일정 때문에 여쭤봅니다."
  - "제 잘못 아닌데요" → "확인해 보니 OO 부분에서 발생한 것으로 보입니다."
- 불필요한 쿠션어 과다 사용(혹시, 죄송하지만, 바쁘시겠지만 중복) 정리
- 요청은 [무엇을] [언제까지] [왜]를 포함

## 5. 메일 양식
```
제목: [팀/프로젝트] 핵심 내용 (요청/공유/회신 요청)

안녕하세요, OO팀 OOO입니다.

[결론/핵심 1~2줄]

■ 내용
-
■ 요청 사항
- 무엇을 / 누가 / 언제까지

확인 부탁드립니다.
감사합니다.
OOO 드림
```

## 6. 공지 양식
```
[공지] 제목

■ 일시:
■ 대상:
■ 내용:
■ 유의 사항:
■ 문의: OOO (내선/메신저)
```

